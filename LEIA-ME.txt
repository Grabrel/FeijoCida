Feijocida - novo icone no GitHub Pages

1. Abra seu repositorio no GitHub e escolha Add file > Upload files.
2. Envie a pasta icons (com icon-192.png, icon-512.png e maskable-512.png) e o sw.js para a RAIZ do repositorio, mantendo a estrutura e substituindo os arquivos de mesmo nome.
3. Faca Commit changes e aguarde o Pages terminar.
4. No Android, se continuar vendo o icone antigo, faca primeiro um backup dos seus dados em Feijocida. Depois remova apenas o atalho/app da tela inicial, abra o site atualizado no Chrome e use Adicionar a tela inicial/Instalar app novamente.

O HTML, manifest e dados do Feijocida nao foram modificados. O sw.js altera apenas o identificador do cache offline para forcar o download das novas imagens.
